# 1917 — 픽셀

영화 〈1917〉(2019)의 주요 장면 15개를 2D 픽셀 아트로 다시 짠 웹앱입니다.
그림·음악·효과음은 이미지나 오디오 파일 없이 **모두 코드로** 만들었습니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # dist/ 에 빌드 + 단일 파일 dist/1917.html
```

`dist/1917.html`은 파일 하나로 되어 있어 브라우저로 바로 열 수 있습니다.

영화가 한 번의 긴 테이크처럼 보이도록 대부분의 전환은 카메라가 멈추지 않고 흘러가는 방식이고,
스코필드가 계단에서 쓰러지는 순간만 영화처럼 완전히 암전됩니다.

## 조작

- 시작 화면: 길게 눌러 봉인을 뜯고, 편지의 **명령을 받고 출발한다** 버튼(또는 편지 아무 곳)을 누르면 출발
- 이야기 장면: 클릭 / 스페이스 = 다음 자막 (전환 중이면 전환을 앞당김)
- 오른쪽 위 버튼: **⌂ 처음으로**(`Esc`) · **건너뛰기 ▸▸**(`→` / `N`) · **♪ 소리**(`M`)
- 질주 게임: `←↑↓→` / `WASD` 이동, `Shift` / `Space` 전력 질주, 마우스로 끌어도 이동
  - 모바일: 왼쪽 아래 스틱(화면 왼쪽 아무 곳을 끌어도 됨)으로 이동, 오른쪽 아래 **질주** 버튼을 누르고 있으면 전력 질주
  - 포탄이 떨어질 자리에는 그림자와 붉은 표시가 먼저 나타납니다
  - 돌격하는 동료 병사와 부딪히면 넘어지고, 포탄에 세 번 맞거나 시간이 다 되면 실패합니다
  - 실패할수록 시간이 늘고 포격이 약해집니다

## 구조

```
src/
  core/gfx.ts       픽셀 그리기, 디더링, 난수, 5x7 픽셀 폰트
  core/audio.ts     Web Audio 합성기: 무드별 작곡 + 효과음
  art/sprites.ts    병사, 나무, 비행기, 트럭, 불, 폭발 …
  art/env.ts        하늘, 능선, 풀밭, 진흙, 폐허, 물
  scenes/title.ts   시작 화면
  scenes/story1.ts  장면 I–VII
  scenes/story2.ts  장면 VIII–XII, XIV–XV
  scenes/run.ts     장면 XIII 질주 게임
  main.ts           장면 순서, 전환, 자막, 입력, 후처리
```

팬 메이드 재구성이며 영화의 대사와 음악을 그대로 옮기지 않았습니다.
